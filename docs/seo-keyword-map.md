## 3. Roman Urdu Search Query Guide

Pakistani parents and students frequently search in Roman Urdu or hybrid Urdu-English. Incorporating these naturally into metadata, FAQs, and image alt text captures untapped high-intent organic traffic:

| Roman Urdu Phrase | Meaning | Suggested Natural Placement |
| :--- | :--- | :--- |
| `tutor chahiye` | "Need a tutor" | FAQ, Alt text, Meta description snippet |
| `ghar k liye tutor` / `home tuition chahiye` | "Looking for home tutor" | FAQ answer discussing In-Person vs Online tutoring |
| `bachon ke liye best tutor` | "Best tutor for children" | Testimonial alt text / FAQ |
| `free demo class milegi?` | "Will we get a free demo class?" | FAQ Question & Answer |
| `fees kitni hai?` / `per hour rates` | "How much are the fees?" | FAQ Question & Answer |
| `online parhai` | "Online study/tutoring" | FAQ / How It Works copy |
